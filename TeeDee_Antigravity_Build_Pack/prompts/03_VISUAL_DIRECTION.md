# Prompt 3 — TeeDee Visual Direction and Design System

Using the reference audit and existing TeeDee identity, define the website's visual direction.

Requirements:
- Preserve the supplied logo.
- Use the established red/orange/graphite/warm-paper palette.
- Maintain Manrope/Inter/IBM Plex Mono direction unless source files show a different approved mapping.
- Translate Ucam's visual composition and rhythm into TeeDee's identity.
- Define container widths, grid, spacing, typography scale, button styles, card styles, image ratios, borders, shadows and responsive rules.
- Define dark and light surface usage.
- Define icon style and graphic motifs.
- Define motion tokens, easing, durations, stagger, reveal patterns and reduced-motion behaviour.
- Define hero video treatment and mobile adaptation.
- Create a component inventory.
- Provide annotated desktop and mobile wireframes or implementation-ready section descriptions.

Do not create a new logo. Do not invent content. Do not proceed to production coding until the direction is documented and reviewed.
Save as `docs/VISUAL_DIRECTION.md` and update `docs/DECISIONS.md`.
