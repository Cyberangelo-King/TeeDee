# Prompt 5 — Media, Video, GIF and Lottie Production

Create a production plan for the required media. Do not create fake project evidence.

Hero:
- cinematic video background;
- 10–20 second loop target;
- desktop and mobile crop;
- MP4/WebM;
- poster image;
- no audio;
- text-safe region;
- natural, credible infrastructure visuals.

Service visuals:
- one consistent image system for every approved service;
- real project media first;
- licensed stock or clearly conceptual generated media only when actual project imagery is unavailable;
- never present stock/AI visuals as completed TeeDee installations.

Motion:
- logo reveal using the existing logo without altering geometry;
- Lottie diagrams for CCTV coverage, power flow, access control, network connectivity and automation only after technical review;
- short GIFs only for small, simple loops;
- MP4/WebM for photographic loops;
- static fallbacks for all motion assets.

For each proposed asset provide:
- asset ID and filename;
- target section;
- creative direction;
- subject and composition;
- aspect ratio;
- duration if video;
- format;
- target file size;
- desktop/mobile requirement;
- accessibility fallback;
- source/licence/permission;
- approval status.

Create `docs/MEDIA_PRODUCTION_PLAN.md` and update `docs/ASSET_REGISTER.md`.
