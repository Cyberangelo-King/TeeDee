# Prompt 7 — Implement Homepage

Build the homepage against the reference audit and approved TeeDee visual direction.

Requirements:
- reproduce the selected Ucam video-background hero composition as closely as practical;
- use the supplied TeeDee logo;
- implement cinematic video with poster/mobile/reduced-motion fallbacks;
- implement all approved homepage sections in the documented order;
- use approved copy and real/licensed media only;
- use high-quality responsive image crops;
- implement meaningful micro-interactions;
- use Lottie only where it explains a system or improves understanding;
- include keyboard and touch equivalents;
- ensure all CTAs work;
- avoid placeholder statistics, fake client logos, fake testimonials and invented project work;
- build desktop and mobile intentionally.

After implementation:
- compare screenshots with the reference at desktop and mobile;
- document differences and reasons;
- test reduced motion;
- run lint/typecheck/build;
- fix all console errors and broken assets.

Do not move to secondary pages until homepage review is complete.
