# Asset and Media Production Brief

## 1. Existing assets
The original TeeDee logo and flyer have already been supplied by the user. They are not new design requests. Treat them as the authoritative starting assets. Place copies in `public/brand/` and preserve the originals untouched.

## 2. Asset register
Create `docs/ASSET_REGISTER.md` and record:
- filename;
- asset type;
- source/owner;
- licence/permission;
- intended placement;
- dimensions/duration;
- format;
- file size;
- mobile variant;
- fallback;
- approval status.

## 3. Logo deliverables
- original logo untouched;
- web-optimised version if quality permits;
- transparent PNG only if supplied/approved;
- SVG only if a true vector master exists or company approves a vector reconstruction;
- light/dark versions only if faithful and legible;
- favicon derived from approved logo artwork;
- optional motion logo: a short, restrained reveal using the original mark without changing its geometry.

Do not redesign or replace the logo. Any proposed refinement must be presented as an optional proposal and separately approved.

## 4. Hero video
### Objective
A cinematic, premium, credible visual introduction to integrated systems.

### Desired shot categories
- architecture/building exterior or interior;
- CCTV/security equipment in context;
- electrical/power equipment;
- solar/inverter details if this is an approved service;
- network cabinet/cabling/connectivity;
- access-control hardware;
- technician preparation and safe work;
- final environment.

### Editing
- 10–20 seconds as a starting loop range;
- seamless or unobtrusive loop;
- no baked-in text;
- no audio requirement;
- dark/neutral exposure in the text-safe region;
- slow, deliberate camera movement;
- natural colour grading;
- no exaggerated sci-fi overlays;
- deliver desktop and mobile crops.

### Technical exports
- WebM and MP4;
- poster WebP/AVIF;
- optional mobile-specific file;
- no audio;
- compressed and tested on mobile network conditions.

## 5. Service media
Prepare one coherent image set per approved service category:
- one landscape card image;
- one wide detail/hero image;
- one portrait crop for mobile/editorial use where necessary;
- one short video loop only where it adds value.

## 6. Motion assets
Possible custom Lottie concepts:
- connected system nodes;
- CCTV coverage/field-of-view diagram;
- power flow diagram;
- access-control sequence;
- network connection flow;
- building automation state flow.

These should be explanatory diagrams, not fake technical representations. A technical reviewer must approve technical accuracy.

## 7. GIF and short-form video
Potential supporting assets:
- 3–5 second loop of an approved device/system detail;
- short logo reveal;
- simple process loop;
- social teaser cut from the hero video;
- short service explainer loops.

Use video/WebM for photographic motion. Reserve GIF for small simple loops.

## 8. Rights and privacy
- Do not reuse Ucam's proprietary images unless separately licensed.
- Do not scrape images from the theme demo and publish them as TeeDee assets.
- Do not use client footage without permission.
- Do not expose security camera views, passwords, access codes, building plans or sensitive site information.
- Keep an asset's original source and permission record.
- If using stock, retain licence evidence.
- If using AI-generated imagery, do not present it as a real TeeDee project or real employee.

## 9. Asset production prompt
“Create a premium, photorealistic visual asset for TeeDee Edge Automations LTD, a practical systems partner working across approved security, power, electrical, access, networking and automation services. Use the existing TeeDee brand palette only as restrained graphic accents: Signal Red #B32632, Signal Orange #E57A2F, Graphite #17191D, Warm Paper #F4F2ED. Show realistic equipment and environments, correct physical proportions, safe working practices and natural cinematic lighting. Avoid generic glowing circuit boards, hacker imagery, fake control rooms, impossible interfaces, invented logos, fake customer sites or text baked into the image. The asset must support the specific website section: [INSERT SECTION]. Composition: [INSERT CROP / TEXT SAFE AREA]. Output: [INSERT FORMAT / RATIO].”
