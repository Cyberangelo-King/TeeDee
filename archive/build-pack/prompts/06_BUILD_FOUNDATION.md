# Prompt 6 — Build Technical Foundation

Only after reference, asset and visual audits are complete:

1. Scaffold the Next.js App Router project with TypeScript strict mode.
2. Configure styling system and design tokens.
3. Configure font loading.
4. Create global layout, metadata foundation and responsive container.
5. Create reusable header, footer, buttons, links, cards, section wrappers and typography components.
6. Create content data files and types.
7. Create motion utilities and reduced-motion hooks/configuration.
8. Create image/video wrappers with fallbacks.
9. Create route skeletons from the PRD.
10. Configure lint, typecheck and production build scripts.
11. Add README and `.env.example`.
12. Add project documentation files.

Keep components small and reusable. Avoid monolithic page components. Do not add a backend/database/CMS unless the approved requirements need one. Run lint, typecheck and build. Record decisions and commands in the build log.
