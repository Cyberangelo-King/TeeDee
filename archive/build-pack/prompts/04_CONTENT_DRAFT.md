# Prompt 4 — Website Copy and Content Model

Use the PRD, flyer audit, company confirmation register and brand voice rules.

Write complete first-draft copy for every approved page:
- Home;
- About;
- Services overview;
- each verified service detail page;
- Industries (only validated segments);
- Projects (only approved real projects; otherwise omit or use a process section);
- Insights (only if approved articles can be produced);
- Contact;
- FAQ;
- Privacy policy draft clearly marked for legal review.

Copy rules:
- human, clear, confident and specific;
- no robotic phrasing or empty superlatives;
- explain customer outcomes;
- avoid technical jargon unless explained;
- no invented facts or guarantees;
- no fake testimonials or case studies;
- no prices unless supplied and approved;
- no unapproved response-time promises;
- never imply a service is available unless confirmed.

Provide:
1. page-by-page copy deck;
2. SEO title and meta description per page;
3. CTA labels and form microcopy;
4. FAQ answers for technical review;
5. list of unresolved claims;
6. typed content data files separated from components.

Use draft status for all unapproved copy. Save in `content/` and update the confirmation register.
