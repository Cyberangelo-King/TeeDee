# Information Architecture and Page Blueprint

## Primary navigation
Home | About | Services | Industries | Projects (conditional) | Insights (conditional) | Contact

Primary action: **Discuss a project** / **Request an assessment** (approve final wording).

## Homepage section order
This is the intended first-pass sequence. Antigravity should inspect Ucam Home 3 and map its actual section rhythm to this content architecture. Do not force every section if the reference uses a different order; document the mapping.

1. Transparent/sticky header
2. Cinematic video hero
3. Brand promise strip: Secure. Power. Automate.
4. Introductory company positioning
5. Featured service cards / service grid
6. About / why TeeDee / company approach
7. Featured capabilities or system integration section
8. Industries / environments
9. Process / how a project works
10. Approved projects / real work (conditional)
11. Technical education / insight teaser (conditional)
12. FAQ accordion
13. Final CTA
14. Footer

## Industries page
Use only confirmed target markets. Candidate groupings:
- Residential properties
- Commercial premises
- Property and facilities
- Institutions and project partners

Each card explains context and needs, not unsupported claims about past clients.

## Projects page
Only publish approved real projects. Project data schema:
- title;
- service category;
- environment/type;
- client name (optional, only with permission);
- location (generalised unless approved);
- brief/problem;
- scope delivered;
- process;
- approved media;
- verified result;
- permission status;
- publication date.

If there are no approved projects, do not publish an empty project archive. Use a “How we work” page/section until evidence is ready.

## Insights page
Possible educational topics:

- What connects an IP camera system?;

Technical reviewer approval required.
