# TeeDee Digital Operations

Connected public website, internal operations application and customer portal proposal for TeeDee Edge Automations LTD.

## Status
Discovery / proposal stage. The repository was empty at assessment time; no production code or deployed system is represented here.

## Documents
- [Strategic Product & Technology Proposal](docs/PROPOSAL.md)
- [Architecture Decision Records](docs/ARCHITECTURE-DECISIONS.md)

## Principles
Maintainable modular architecture; reliable offline sync; owner-led business administration; separate disclosed platform operator access; RBAC + ABAC; auditable resource transactions; secure-by-design delivery; measurable operational ROI.

Stack and estimates are proposed pending discovery, proof of concept and owner approval.
